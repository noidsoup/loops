# Gotchas

One line each: the trap, then the fix or the page with details.

- **Your checkout is live for every project.** `~/.loops` symlinks to `~/Code/loops`, so a half-finished branch changes how agents behave everywhere. Do risky work in a worktree; check `readlink ~/.loops` (`AGENTS.md` invariant 8).
- **Editing an emitted file does nothing lasting.** `.cursor/rules/loops-*.mdc` and `.claude/skills/loops-*/` are regenerated by `npm run emit`; edit `loops/<name>/loop.md` / `loop.yaml` and commit the regenerated files in the same change ([[adapters-emit-and-install-global]]).
- **`npm test` can't catch emit drift; `npm run verify` can.** `test/emit.test.js` re-emits into the working tree, so the drift check inside `npm test` always passes. `.verify.sh` runs `emit --check` first ([[ci-and-verify-gate]], commit `cc18520`). Run `git status` after tests.
- **A new loop touches four places.** `loop.yaml` (name, version, valid `model_class`), the `dispatcher/loop.md` table, `dispatcher/loop.yaml` `classification.options`, and the README catalog. Tests fail if one is missing (`AGENTS.md` invariant 3; [[loop-catalog]]).
- **Shared docs must not name private harnesses or model stacks.** `test/model-classes.test.js` has the banned list; personal routing goes in gitignored `adapters/MODEL_CLASSES.local.md` ([[0003-portable-model-classes-local-override]]).
- **Personas are not loops.** Never add one to the dispatcher; every persona a loop names must exist in `personas/` and be named in that loop's `loop.md` ([[loop-personas]]).
- **`install-global.js` writes to your home folder.** Preview with `npm run install:global:dry`; run the real install only when asked (`AGENTS.md` invariant 7).
- **Bare skill names collided with another pack.** Another installed pack had its own `plan-and-implement`, `tdd`, `sar`. Everything loops emits is `loops-*`, and install ships a resolution rule that says `loops-*` wins ([[0002-namespace-emitted-files-loops-prefix]]).
- **Root `CLAUDE.md` is not the entry point.** Local tooling rewrites it and it is excluded via `.git/info/exclude`; the tracked entry is `.claude/CLAUDE.md`, which imports `AGENTS.md` ([[0005-claude-code-entry-point-agents-md]]).
- **Per-project emit lands in the wrong place unless the clone is named exactly `.loops`.** Only then does emit write to the parent project root ([[per-project-install]]).
- **`--dry-run` once created `~/.claude/skills/`.** Fixed in commit `3106f9e`; if dry runs leave files again, that guard regressed.
- **Not part of loops:** `scripts/yin-*` and `scripts/LlamaServerQwythos-patched.xml` set up a llama.cpp server on a separate Windows box (`AGENTS.md`). Don't "clean them up" as loops code without asking.
