# AGENTS.md — loops

**This repo:** loops, portable workflow playbooks for AI coding agents in Cursor and Claude Code. A user says "use the loops" (or just describes the job) and the dispatcher routes the request to one loop: plan-and-implement, tdd, sar, adversarial-gate, reproduce-and-fix, migrate, explain-codebase, de-ai-ify, swarm or use-the-loop. Installed once per machine (`~/.loops`) or per project (cloned into the project as `.loops`).
**Stack:** Markdown + YAML loop definitions; Node.js 18+ adapters (`adapters/emit.js`, `adapters/install-global.js`) with no npm dependencies; tests on `node --test`; GitHub Actions CI on Node 20. Optional Python sidecar for LanceDB doc search (`requirements-lancedb.txt`).

Claude Code loads this file through `.claude/CLAUDE.md`; always-on rules are in `.claude/rules/`.

**Project wiki:** read `wiki/index.md` before non-trivial work; open pages it points to only when relevant.
After a repeated failure, check `wiki/gotchas.md`. Writing to the wiki: follow `wiki/SCHEMA.md`.

## Invariants (always apply)

1. **Verify before done.** Run `npm run verify` and paste the real result. See `.claude/rules/verify-before-done.md`.
2. **Edit the canonical source, never the emitted copies.** Loops live in `loops/<name>/loop.md` and `loops/<name>/loop.yaml`, the router in `dispatcher/`. `.cursor/rules/loops-*.mdc` and `.claude/skills/loops-*/` are generated by `adapters/emit.js`: after editing a loop, run `npm run emit` and commit the regenerated files in the same change.
3. **The catalog stays in sync.** A new or renamed loop needs `loops/<name>/loop.yaml` with a matching `name`, a `version`, and phases whose `model_class` is `high-reasoning`, `workhorse` or `cheap-fast` (`schema/loop.schema.json`). It also needs a row in the `dispatcher/loop.md` table, an entry in `dispatcher/loop.yaml` `classification.options`, and a mention in the README catalog. Tests enforce all of it.
4. **Personas are review lenses, not loops.** Every persona named in `loops/<name>/loop.yaml` must exist as `personas/<persona>.md` and appear in the same loop's `loops/<name>/loop.md`. Never add a persona to the dispatcher.
5. **Self-correcting loops cite the contract.** A loop with `self_correcting: true` must set `self_correcting_max_revisions`, and its `loops/<name>/loop.md` must point at `contracts/self-correcting.md`.
6. **Shared docs stay portable.** README, `INSTALL*.mdc`, `INSTALL-CLAUDE.md`, `adapters/MODEL_CLASSES.md`, the dispatcher and every `loops/<name>/loop.md` must not name private agent harnesses or model stacks; the banned names are in `test/model-classes.test.js`. Personal stacks go in the gitignored `adapters/MODEL_CLASSES.local.md`.
7. **`adapters/install-global.js` writes outside the repo** (`~/.loops`, `~/.cursor/rules`, `~/.cursor/skills`, `~/.claude/rules`, `~/.claude/skills`). Run `npm run install:global` only when asked; preview with `npm run install:global:dry`.
8. **This checkout may be live.** If `readlink ~/.loops` points here, agents in every project on the machine read this checkout's loop files, so a half-finished branch changes their behavior too.
9. **Secrets only in `.env`** (gitignored). Building and testing need none; `.env.example` lists only the optional LanceDB settings.

## Definition of done (commands)

```bash
npm run verify               # .verify.sh: emit drift check, then npm test — the agent gate
npm test                     # node --test test/*.test.js && node adapters/emit.js --check (what CI runs)
npm run emit                 # regenerate emitted rules + skills (node adapters/emit.js [loop])
npm run emit:check           # fail if emitted files differ from the canonical loops
npm run install:global:dry   # print the global install plan; changes nothing
```

`npm test` re-emits into the working tree (`test/emit.test.js`), so its own drift check
always passes. `npm run verify` checks drift first; run `git status` after tests.
